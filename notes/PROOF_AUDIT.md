# Proof and implementation audit

This is an AI-led internal audit, not independent peer review.

| Claim | Conditions checked | Main failure avoided |
|---|---|---|
| Native-summary nonidentification | Only jointly evolving native pairs are observed; counterfactual swaps are not given | Claiming impossibility with a complete executable counterfactual model |
| Fork identification | Fresh parent/task/history draws, independent development pairs, no interference, declared module boundary | Attributing better parents or accumulated external state to the improver |
| Performance-difference telescoping | Full sufficient Markov state; same initial law; fixed-author continuation value | Treating native score alone as sufficient state |
| Rectangular robust intervals | Rowwise independent uncertainty and bounded terminal reward; extreme rows attain Bellman endpoints | Calling a rectangular relaxation sharp for a coupled persistent parameter |
| Persistent adapter | One adapter per complete audit; finite fixed set versus arbitrary mixtures distinguished | Interpreting an inadmissible mid-audit adapter switch as a real negative effect |
| Endpoint detection boundary | Contrast distortion b; endpoint-only samples; uniform null/alternative quantifiers | Confusing observed-effect certification at b with uniform power requiring gamma > 2b |
| Local testing lower bound | Restricted b and gamma keep Bernoulli parameters away from 0 and 1; KL data processing | Claiming the same rate uniformly at probability boundaries |
| Empirical Bernstein certificate | IID development-level bounded observations; fixed n; declared comparison family | Treating descendants or truth-table bits as independent replications; optional stopping |
| Nested replication | Conditional IID fresh audits; development variability is retained | Eliminating outer variance with infinitely many inner samples |
| Meta-tag invariance | Seed's four leaves all use unrestricted uniform reset; task evaluation unchanged | Mistaking a complete-system semantic intervention for a harmless renaming |

## Executed validation

- Original 35 tests plus 35 new interpreter, scalar-reference, persistent-adapter, and tag-invariance tests: 70 passing.
- The original exact, sensitivity, and lineage data were regenerated; normalized CSV rows agree exactly.
- All 15 original confirmation intervals recomputed from raw outcomes.
- All 24 tree-study intervals (12 per study) recomputed from exact integer sufficient statistics.
- All 18 diagnostic dividends and 15 nonidentity adapter-effect intervals recomputed from integer statistics.
- Raw archives, protocol and executed-source hashes checked; independent seed prefixes replayed bitwise for every new task family.
- Original robust TV optimization is checked against SciPy linear programming; the new rowwise persistent-adapter relaxation is checked against brute-force enumeration in small random systems.

## Remaining substantive uncertainty

No numerical test establishes that the integrated framing is sufficiently novel for ICLR, or that the bounded experiments predict behavior of language-model agents. The endpoint contamination theorem is intentionally a specialization of robust-testing arguments. The main potential contribution is the explicit comparison and intervention boundary, together with a reproducible separation between mechanism gain and inheritance gain.
