# The Causal Recursion Dividend

Theory-first research on identifying improvement of an improver and the additional effect of recursive inheritance.

This repository is being populated with an explicit causal specification, complete proofs, reproducible CPU experiments, and a paper draft. The protected evaluator, resource accounting, and nonrecursive fixed-author comparator are part of the experimental contract.

No claim of broad autonomous recursive self-improvement is made. Submission readiness will be assessed against the completed proofs, executed experiments, and remaining limitations.
